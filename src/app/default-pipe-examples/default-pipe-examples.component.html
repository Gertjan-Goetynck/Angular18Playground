Default pipes

Source

Angular supplies us with some default pipes for easy data formatting or manipulation.

Some of these pipes are influenced by the app locale. For these settings, look at app.config.ts and main.ts

  • Date formatting:
    • Unformatted value: {{ currentDate }}
    • Formatted value with date pipe: {{ currentDate | date }}
  • Currency formatting:
    • Unformatted value: {{ currencyValue }}
    • Formatted value with currency pipe: {{ currencyValue | currency }}
  • Decimal formatting:
    • Unformatted value: {{ numberValue }}
    • Formatted value with decimal pipe: {{ numberValue | number }}
    • Formatted value with decimal pipe and 2 decimal places: {{ numberValue | number: '1.2-2' }}
  • Percentage formatting:
    • Unformatted value: {{ percentageValue }}
    • Formatted value with percent pipe: {{ percentageValue | percent }}
  • Async pipes can be used to subscribe to an observable. Click the button to update the value inside of it and see this in action.
